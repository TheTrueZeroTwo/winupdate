# Logs and Reports

Persistent output is stored under:

```text
C:\ProgramData\WinUpdateMspHelper\Logs
C:\ProgramData\WinUpdateMspHelper\Reports
```

Logs are transcript-style text logs. Reports are JSON files written by helper actions such as disk checks, system snapshots, network snapshots, and event summaries.

These files are intentionally persistent so the technician can review what happened after a remote session or after a scheduled task run.
